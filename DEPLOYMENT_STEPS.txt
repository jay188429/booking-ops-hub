5단계: 테스트 (로컬에서)
================================================================================

터미널에서:

$ cd /Users/hyunjaeyoo/dev/booking-hub
$ npm run dev

브라우저에서:
1. http://localhost:5173 (또는 출력된 URL) 접속
2. 로그인 (Google OAuth)
3. "새 예약 추가" 폼 작성:
   - 고객사: 테스트 회사
   - 서비스: 웹사이트 개발
   - 날짜: 오늘 또는 내일
   - 시간: 14:00
   - 주소: 서울 강남구 (선택)
4. "예약하기" 클릭

결과 확인:
✅ Slack 채널에 메시지 도착
✅ Supabase 대시보드 → Edge Functions → Logs에서 "200 OK" 확인

실패 시:
❌ Slack 메시지 미수신
   - Webhook URL 확인 (Secrets 설정 확인)
   - Slack 채널 권한 확인
❌ 405/404 에러
   - 함수가 배포되었는지 확인
   - 함수명 오타 확인
❌ 400 Bad Request
   - "Webhook URL not configured" 에러
   - Secrets에서 SLACK_WEBHOOK_URL 설정 확인
